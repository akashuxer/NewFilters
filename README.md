# New Filters

Standalone Filters UI prototype using Arvo Design System components.

This repository intentionally contains only the Filters experience, Smart Input, Measure Builder, and Filters-specific styles. The Arvo Design System is consumed as the external `@arvo/js` dependency; Arvo source, Gallery, Foundations, and the full playground are not included.

## Structure

- `src/Filters.ts` - Filters UI and Filter Menu behavior
- `src/SmartInput.ts` - Smart expression input and Measure Builder
- `src/filters.scss` - Filters-specific styles
